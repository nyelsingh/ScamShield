# 🛡️ ScamShield

**Know Before You Click.**

ScamShield is a Chrome extension that helps users identify phishing attempts, scam websites, and suspicious web pages before interacting with them. With a single click, ScamShield analyzes the current website using multiple security checks and generates an easy-to-understand security report with a trust score and actionable recommendations.

---

##  Features

* 🔒 HTTPS security verification
* 🌐 Domain reputation analysis
* 🔗 URL structure and risk analysis
* 🎭 Brand impersonation detection
* 📝 Scam keyword detection
* 📄 Form detection and inspection
* 📊 Trust score (0–100)
* 🚦 Website safety classification

  * 🟢 Safe
  * 🟡 Caution
  * 🔴 Dangerous
* 📋 Detailed security report
* 💡 Personalized security recommendations
* 🕒 Scan timestamp
* 📚 Local scan history
* 🚫 Detection of browser-blocked pages
* 🔵 Proper handling of browser internal pages

##  How It Works

1. Open the ScamShield extension.
2. Click **Scan Website**.
3. ScamShield analyzes the active webpage.
4. Multiple security checks are performed.
5. A trust score and security report are generated.
6. Recommendations help users make safer browsing decisions.
